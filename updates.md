## 2026-07-29 — the OTHER 5 seconds: discover(cwd) froze the painted UI

Cause: `App.tsx` ran `discover(cwd)` 10ms after mount — a fully synchronous depth-4 walk with a `statSync` per file, which blocks Bun's event loop for however long the shell's cwd takes (home dir / big tree = seconds); the picker paints and then eats no input until it finishes.
